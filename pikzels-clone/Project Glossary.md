# Project Glossary

## Overview

This document defines the key terms and concepts used throughout the Thumbnail Maker Studio project.

## Terms

### A

#### API (Application Programming Interface)
A set of protocols and tools for building software applications. In this project, APIs are used to communicate between the frontend and backend.

#### Authentication
The process of verifying the identity of a user. The project uses JWT (JSON Web Tokens) for authentication.

### B

#### Batch Editing
The ability to apply the same edits to multiple thumbnails simultaneously.

#### Backend
The server-side component of the application, built with Node.js, Express, and TypeScript.

### C

#### Controller
A component in the MVC architecture that handles user requests and returns responses. Controllers in this project are located in the `src/modules` directory.

#### CSS (Cascading Style Sheets)
A stylesheet language used for describing the presentation of a document written in HTML. Used extensively in the frontend for styling.

### D

#### Dashboard
The main user interface page that provides an overview of the user's thumbnails, projects, and account information.

#### Database
An organized collection of structured information. This project uses SQLite with Prisma ORM for database management.

#### Dark Mode
A color scheme that uses light-colored text on a dark background, reducing eye strain in low-light conditions.

### E

#### Editing Tools
Features that allow users to modify thumbnails, including filters, text overlays, and drawing tools.

#### Endpoint
A specific URL where an API can be accessed. For example, `/api/auth/register` is an endpoint for user registration.

### F

#### Filter
A tool that modifies the visual appearance of a thumbnail, such as adjusting brightness, contrast, or saturation.

#### Frontend
The client-side component of the application, built with React, TypeScript, and Vite.

### G

#### GitHub
A web-based platform for version control and collaboration. Used for hosting the project repository.

### H

#### History/Undo
A feature that allows users to revert changes made to a thumbnail.

### J

#### JSON (JavaScript Object Notation)
A lightweight data interchange format that is easy for humans to read and write and easy for machines to parse and generate.

#### JWT (JSON Web Token)
An open standard for creating access tokens. Used in this project for user authentication.

### K

#### Keyboard Shortcuts
Key combinations that provide quick access to editing functions.

### L

#### Layers
Separate elements in a thumbnail that can be edited independently, such as text overlays or drawing elements.

### M

#### Migration
A file that describes changes to the database schema. Created using Prisma Migrate.

#### Model
A representation of a database table in the Prisma schema.

### N

#### Node.js
A JavaScript runtime built on Chrome's V8 JavaScript engine. Used for the backend server.

### O

#### ORM (Object-Relational Mapping)
A programming technique for converting data between incompatible type systems. Prisma is the ORM used in this project.

### P

#### Prisma
A next-generation ORM for Node.js and TypeScript. Used for database operations in this project.

#### Project
A container for organizing related thumbnails.

### R

#### Route
A mapping between a URL pattern and a handler function. Defines how the application responds to client requests.

### S

#### Schema
The structure of the database, defining tables, fields, and relationships.

#### Service
A component that contains business logic and interacts with the database. Services in this project are located in the `src/modules` directory.

#### Settings
User preferences that customize the application experience, such as theme, language, and notification preferences.

#### Share Link
A URL that allows others to view a thumbnail without requiring authentication.

#### SQLite
A C-language library that implements a small, fast, self-contained, high-reliability, full-featured, SQL database engine.

### T

#### Tailwind CSS
A utility-first CSS framework used for styling the frontend.

#### Testing
The process of evaluating and verifying that a software application works as expected.

#### Thumbnail
A small image representation of a larger image or video, typically used for quick identification and organization.

#### TypeScript
A strongly typed programming language that builds on JavaScript. Used for both frontend and backend development in this project.

### U

#### Unit Test
A level of software testing where individual units/components of a software are tested.

#### User
A person who registers and uses the Thumbnail Maker Studio application.

### V

#### Vite
A build tool that aims to provide a faster and leaner development experience for modern web projects.

### W

#### Watermarking
The process of adding a visible or invisible identifier to a thumbnail to protect copyright.
